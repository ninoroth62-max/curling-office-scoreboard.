CURLING OFFICE – WINDOWS VERSION ================================ INSTALLATION AUF DEM HP-LAPTOP 1. ZIP-Datei entpacken, zum Beispiel auf den Desktop. 2. Python 3 fuer Windows installieren: https://www.python.org/downloads/windows/ Beim Installieren "Add Python to PATH" aktivieren. 3. Doppelklick auf start_curling_office.bat. 4. Das schwarze Fenster offen lassen. 5. Auf dem Laptop im Browser http://localhost:8765 oeffnen. TV-ANZEIGE AUF EINEM ZWEITEN GERAET 1. Laptop und TV-PC muessen im gleichen WLAN/LAN sein. 2. Im schwarzen Startfenster steht die TV-Adresse, z.B. http://192.168.1.25:8765/tv 3. Diese Adresse im Browser des TV-PCs oeffnen. 4. Bei einer Windows-Firewall-Abfrage Netzwerkzugriff fuer private Netzwerke erlauben. Falls die Verbindung blockiert wird, muss eingehender TCP-Port 8765 freigegeben werden. 5. TV-Browser auf Vollbild stellen (F11). BEDIENUNG - Curl Office: Teams, Farben, Club und Rink einstellen. - Eingabe-Terminal: Modus und Endanzahl waehlen, Steine eingeben. - Mixed Doubles: maximal 6 Ends. Andere Modi: maximal 8 Ends. - X: Aufgabe-Funktion. OK = Team 1 gibt auf, Abbrechen = Team 2 gibt auf. - Spielstand wird in spielstand.json im Programmordner gespeichert. WICHTIG Laptop und TV muessen im selben lokalen Netzwerk sein. Der Laptop muss eingeschaltet bleiben und das schwarze Server-Fenster darf nicht geschlossen werden. Dies ist eine erste lokale Version, kein signierter Windows-Installer.
